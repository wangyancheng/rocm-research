# GDB 常用操作速查手册

## 一、启动与退出

| 操作           | 命令                             | 说明                   |
| :------------- | :------------------------------- | :--------------------- |
| 直接调试       | `gdb ./program`                  | 调试可执行文件         |
| 带参数启动     | `gdb --args ./program arg1 arg2` | 传递命令行参数         |
| 附加到运行进程 | `gdb -p <PID>`                   | 实时调试正在运行的进程 |
| 调试 core 文件 | `gdb ./program core`             | 分析崩溃时的内存状态   |
| 退出 GDB       | `quit` 或 `q` 或 `Ctrl+d`        | 退出调试器             |
| 查看版本       | `gdb --version`                  | 查看当前 GDB 版本      |

> **编译要求**：使用 `-g` 选项编译以包含调试信息：
>
> bash
>
> ```
> gcc -g program.c -o program
> ```

## 二、执行控制

| 操作                   | 命令           | 缩写 | 说明                      |
| :--------------------- | :------------- | :--- | :------------------------ |
| 运行程序               | `run [args]`   | `r`  | 启动或重新启动程序        |
| 继续执行               | `continue`     | `c`  | 继续运行到下一个断点      |
| 单步执行（不进入函数） | `next`         | `n`  | 执行下一行，跳过函数调用  |
| 单步执行（进入函数）   | `step`         | `s`  | 执行下一行，进入函数内部  |
| 执行完当前函数         | `finish`       | —    | 运行直到当前函数返回      |
| 运行到指定行           | `until <行号>` | —    | 直接运行到 until 后的行处 |
| 终止程序               | `kill`         | —    | 终止正在调试的程序        |

> **小技巧**：GDB 会自动记录最新输入的命令，直接按 **Enter** 即可重复执行上一条命令。

## 三、断点管理

### 3.1 设置断点

| 操作                 | 命令                      | 示例                 |
| :------------------- | :------------------------ | :------------------- |
| 在函数处设断点       | `break <函数名>`          | `break main`         |
| 在行号处设断点       | `break <行号>`            | `break 15`           |
| 在指定文件的行设断点 | `break <文件名>:<行号>`   | `break main.c:15`    |
| 条件断点             | `break <位置> if <条件>`  | `break 20 if i == 5` |
| 给已有断点加条件     | `condition <编号> <条件>` | `condition 2 i == 0` |

### 3.2 管理断点

| 操作         | 命令               | 缩写  | 说明                     |
| :----------- | :----------------- | :---- | :----------------------- |
| 查看所有断点 | `info breakpoints` | `i b` | 显示断点编号、状态、位置 |
| 删除断点     | `delete <编号>`    | `d`   | 删除指定编号的断点       |
| 禁用断点     | `disable <编号>`   | —     | 关闭断点但不删除         |
| 启用断点     | `enable <编号>`    | —     | 重新启用被禁用的断点     |
| 清除断点     | `clear <位置>`     | —     | 清除指定位置的断点       |

> **注意**：只要 GDB 不退出，新断点的编号会一直递增。

## 四、数据查看

### 4.1 变量与表达式

| 操作                  | 命令                  | 缩写       | 说明                             |
| :-------------------- | :-------------------- | :--------- | :------------------------------- |
| 打印变量/表达式       | `print <expr>`        | `p`        | 查看变量或表达式的值             |
| 打印数组/指针连续元素 | `print <arr>@<count>` | `p`        | 如 `p arr@10` 打印数组前10个元素 |
| 查看局部变量          | `info locals`         | `i locals` | 显示当前函数所有局部变量         |
| 查看类型信息          | `ptype <变量>`        | —          | 显示变量或类型的详细信息         |
| 自动显示变量          | `display <变量>`      | —          | 每次停顿时自动显示该变量         |
| 取消自动显示          | `undisplay <编号>`    | —          | 取消自动显示                     |
| 临时修改变量          | `set var <变量>=<值>` | —          | 调试时临时修改变量值             |

### 4.2 查看源码

| 操作         | 命令                             | 缩写 | 说明                       |
| :----------- | :------------------------------- | :--- | :------------------------- |
| 显示源码     | `list`                           | `l`  | 显示当前源代码附近几行     |
| 指定位置显示 | `list <函数名>` 或 `list <行号>` | `l`  | 显示指定函数或行附近的代码 |
| 指定文件位置 | `list <文件名>:<行号>`           | `l`  | 如 `list main.c:10`        |
| 进入上下屏幕 | tui enable                       |      |                            |

## 五、栈帧与回溯

| 操作             | 命令           | 缩写  | 说明                     |
| :--------------- | :------------- | :---- | :----------------------- |
| 查看调用栈       | `backtrace`    | `bt`  | 显示函数调用栈           |
| 切换到指定栈帧   | `frame <编号>` | `f`   | 切换到指定栈帧查看上下文 |
| 查看当前栈帧信息 | `info frame`   | `i f` | 显示当前栈帧的详细信息   |

## 六、内存与寄存器检查

### 6.1 内存查看（`x` 命令）

格式：`x/<count><format><size> <address>`

| 参数     | 说明                                               |
| :------- | :------------------------------------------------- |
| `count`  | 显示单元数量                                       |
| `format` | `x`(十六进制)、`d`(十进制)、`s`(字符串)、`c`(字符) |
| `size`   | `b`(字节)、`h`(半字)、`w`(字)、`g`(8字节)          |

**示例**：

| 命令                   | 含义                             |
| :--------------------- | :------------------------------- |
| `x/4xw 0x7fffffffe000` | 以十六进制显示4个字              |
| `x/10cb buffer`        | 以字符格式显示 buffer 前10个字节 |
| `x/s 0x地址`           | 以字符串格式显示内存内容         |

### 6.2 寄存器

| 操作           | 命令              | 说明               |
| :------------- | :---------------- | :----------------- |
| 查看所有寄存器 | `info registers`  | 显示所有寄存器值   |
| 修改寄存器     | `set $eax = <值>` | 修改指定寄存器的值 |

## 七、观察点（Watchpoint）

监视变量变化，当变量被读写时暂停程序：

| 操作         | 命令            | 说明               |
| :----------- | :-------------- | :----------------- |
| 监视变量写入 | `watch <变量>`  | 变量被修改时暂停   |
| 监视变量读取 | `rwatch <变量>` | 变量被读取时暂停   |
| 监视读写     | `awatch <变量>` | 变量被读或写时暂停 |
| 查看监视窗口 | `info watch`    | 查看所有观察点     |
| 删除观察点   | `delete <编号>` | 删除指定观察点     |

## 八、多线程调试

| 操作             | 命令                       | 说明                     |
| :--------------- | :------------------------- | :----------------------- |
| 查看所有线程     | `info threads`             | 显示所有线程及其状态     |
| 切换线程         | `thread <id>`              | 切换到指定线程           |
| 所有线程执行命令 | `thread apply all <命令>`  | 如 `thread apply all bt` |
| 锁定当前线程     | `set scheduler-locking on` | 单步时只执行当前线程     |

**典型流程**：

text

```
(gdb) info threads
(gdb) thread 2
(gdb) bt
```

## 十、常用命令速查表

| 命令        | 缩写 | 功能               |
| :---------- | :--- | :----------------- |
| `run`       | `r`  | 运行程序           |
| `continue`  | `c`  | 继续执行           |
| `next`      | `n`  | 单步（不进入函数） |
| `step`      | `s`  | 单步（进入函数）   |
| `break`     | `b`  | 设置断点           |
| `info`      | `i`  | 查看信息           |
| `print`     | `p`  | 打印变量值         |
| `backtrace` | `bt` | 查看调用栈         |
| `delete`    | `d`  | 删除断点/观察点    |
| `quit`      | `q`  | 退出 GDB           |

------

> **提示**：调试优化后的代码（`-O2`/`-O3`）时，变量可能不可见或执行顺序混乱，建议调试时使用 `-O0` 关闭优化。
